# Sports Stats Explorer

A sports analytics dashboard that settles arguments with actual data.

We are building a website that answers real questions about a sports league, such as:

- Who are the best scorers?
- Which teams win close games?
- Is being "clutch" real, or just luck?

Along the way you will learn SQL (joins and aggregation), Python, charts, and how to put a dashboard online. No experience is needed.

## How the project works

Data flows through five steps, from left to right:

```
CSV files  ->  Database  ->  SQL queries  ->  Python  ->  Dashboard
```

| Step | What it is | Where it lives |
|---|---|---|
| 1. CSV files | Plain spreadsheet-like files with teams, players, games, and stats | `data/raw/` |
| 2. Database | A SQLite database built from the CSV files. It is one file on your computer. | `db/league.db` (created by you) |
| 3. SQL queries | Short programs that ask the database a question, like "who scored the most points?" | `sql/` |
| 4. Python | Runs a SQL file and hands back the answer as a table (a pandas DataFrame) | `src/sports_stats/db.py` |
| 5. Dashboard | Turns each table into a chart on a web page, using Streamlit and Plotly | `app/` |

**Key idea:** each question gets its own SQL file and its own dashboard page. That means different people can work on different questions at the same time without getting in each other's way.

**Note:** the data right now is a fake league, generated by `scripts/generate_sample_data.py`. It lets everyone start immediately. Swapping in a real league is one of the tasks in the roadmap.

## Getting started

### What you need

- **Python 3.10 or newer.** Check with `python3 --version`.
- **Git.** Check with `git --version`.
- **A GitHub account** and a fork of this repo.

New to forks and Git? Read [CONTRIBUTING.md](CONTRIBUTING.md) first. It explains every Git step in detail.

### Setup steps

Run these commands in your terminal, one at a time.

**Step 1. Download your fork.** Replace `<your-username>` with your GitHub username.

```bash
git clone https://github.com/<your-username>/sports-stats-explorer.git
cd sports-stats-explorer
```

**Step 2. Connect to the original club repo.** This is called "upstream". It lets you download updates that other people have added.

```bash
git remote add upstream https://github.com/data-science-ucsb/sports-stats-explorer.git
```

**Step 3. Create a virtual environment.** This keeps this project's Python packages separate from everything else on your computer.

```bash
python3 -m venv .venv
```

**Step 4. Turn the virtual environment on.** You need to do this every time you open a new terminal.

```bash
# Mac or Linux:
source .venv/bin/activate

# Windows:
.venv\Scripts\activate
```

You will know it worked when you see `(.venv)` at the start of your terminal line.

**Step 5. Install the packages.**

```bash
pip install -r requirements.txt
```

**Step 6. Build the database.** This reads the CSV files and creates `db/league.db`.

```bash
python scripts/load_data.py
```

**Step 7. Run the tests.**

```bash
pytest
```

You should see 1 test pass and 3 tests skipped. The skipped tests are for questions nobody has written yet. They will start running automatically once someone writes the SQL.

**Step 8. Start the dashboard.**

```bash
streamlit run app/Home.py
```

Your browser should open the dashboard. Click "Top Scorers" in the sidebar to see a working page. The other three pages show a "Not built yet" message. Those are the ones we will build.

To stop the dashboard, press `Ctrl + C` in the terminal.

## The data

The database has four tables. You can see the full details in `db/schema.sql`.

| Table | Each row is... | Important columns |
|---|---|---|
| `teams` | one team | `team_id`, `name`, `abbreviation` |
| `players` | one player | `player_id`, `name`, `team_id`, `position` |
| `games` | one game | `game_id`, `game_date`, `home_team_id`, `away_team_id`, `home_score`, `away_score` |
| `player_game_stats` | one player in one game | `game_id`, `player_id`, `minutes`, `points`, `rebounds`, `assists` |

### How the tables connect

The tables point to each other using ID numbers. SQL "joins" use these IDs to combine tables.

- `players.team_id` matches `teams.team_id`, so you can find which team a player is on.
- `games.home_team_id` and `games.away_team_id` both match `teams.team_id`.
- `player_game_stats.game_id` matches `games.game_id`.
- `player_game_stats.player_id` matches `players.player_id`.

### Try the database yourself

After running `python scripts/load_data.py`, open the database in your terminal:

```bash
sqlite3 db/league.db
```

Then try a few queries (type `.quit` to leave):

```sql
SELECT * FROM teams;
SELECT * FROM games LIMIT 5;
SELECT name, position FROM players WHERE team_id = 1;
```

If you prefer a point-and-click tool, install the free [DB Browser for SQLite](https://sqlitebrowser.org/).

## How to add a new question to the dashboard

Every page follows the same four steps. The finished Top Scorers example shows each one, so read it first:
`sql/top_scorers.sql` and `app/pages/1_Top_Scorers.py`.

1. **Write the SQL.** Open the matching file in `sql/` (for example `sql/team_standings.sql`). Read the hints at the top, then write your query below them. Test it in `sqlite3` first.
2. **Open the matching page.** For example `app/pages/2_Standings.py`. If you are making a brand new question, copy `1_Top_Scorers.py` and rename it.
3. **Make a chart.** Use [Plotly Express](https://plotly.com/python/plotly-express/) to turn the table into a bar chart, line chart, or whatever fits the question.
4. **Check it.** Run `pytest` to see that your test passes, then run `streamlit run app/Home.py` and look at your page.

When it works, open a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Troubleshooting

**`command not found: python3` or `python`**
Python is not installed or not on your path. Install it from [python.org](https://www.python.org/downloads/).

**`ModuleNotFoundError: No module named 'pandas'` (or streamlit, plotly)**
Your virtual environment is not turned on, or the packages are not installed. Run the activate command from Step 4, then `pip install -r requirements.txt`.

**`FileNotFoundError: ... league.db not found`**
You have not built the database yet. Run `python scripts/load_data.py`.

**A page says "Not built yet"**
That is expected for the TODO pages. It means the matching `.sql` file in `sql/` is still empty. Writing that query is the task.

**`git pull upstream main` says `'upstream' does not appear to be a git repository`**
You skipped Step 2. Run the `git remote add upstream ...` command from that step.

**Something else is broken**
Copy the full error message and ask in the club channel. Everyone gets stuck, and the error message is the most useful thing to share.
